# 🎬 FONEX IPTV | Premium IPTV Experience

LG webOS platformu için modern IPTV uygulaması – Akıllı arayüz, premium streaming, kolay kurulum.

## Başlıca Özellikler
- TV uzaktan kumanda, HLS/M3U playlist desteği
- Tema ve karanlık mod desteği
- TV'ye özel performans ve erişilebilirlik

## Kurulum
1. Kodları klonla:
   ```bash
   git clone https://github.com/umexxxx2595/iptv_player.git
   cd iptv_player
   npm install
   ```

2. Geliştirici modunda başlat:
   ```bash
   npm run dev
   ```

3. webOS üretim derlemesi ve yükleme:
   ```bash
   npm run build:webos
   npm run webos:deploy
   ```
